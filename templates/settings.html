Email notifications

After each check (daily, or when you click Check Audible now), Audible Watcher sends one digest email listing any new books from your watched authors and series. No new books, no email. It sends through your own email account, so the message comes from you, to you.

How to set up Gmail (step by step)

Gmail doesn't let apps use your normal password. Instead you create an app password: a 16-letter password just for Audible Watcher that you can revoke anytime without changing your real password.

  1. Turn on 2-Step Verification (app passwords require it). Open Google Account → 2-Step Verification, sign in, and follow the prompts. Skip this if it's already on.
  2. Create the app password. Open Google Account → App passwords, type the name Audible Watcher, and click Create.
  3. Copy the 16-letter code Google shows (it looks like abcd efgh ijkl mnop). Google only shows it once; if you lose it, just delete it and create a new one.
  4. Fill in the form below:
    • SMTP server smtp.gmail.com, port 465, security SSL (already filled in by default).
    • Email address: your full Gmail address.
    • App password: paste the code (spaces are fine).
    • Send notifications to: where you want the emails — your Gmail address or any other address.
  5. Tick “Send me an email…”, click Save settings, then click Send test email. The test should arrive within a minute (check Spam the first time, and mark it “Not spam”).

Google Workspace (work or school) accounts: your administrator may have turned app passwords off. If the App passwords page says it isn't available, use a personal Gmail account instead.

Email not working? Troubleshooting
“Username and password not accepted” / authentication failed
You probably entered your normal password. Create an app password (steps above) and paste it in. Also check the email address is complete (you@gmail.com, not just you).
“Wrong version number”, SSL errors, or the test hangs
The port and security setting don't match. Use port 465 with SSL, or port 587 with STARTTLS.
“Could not connect” / name not found
Check the SMTP server name for typos. If this app runs on a home server or NAS, make sure it can reach the internet and that your network doesn't block outgoing mail ports.
Test says it was sent, but nothing arrives
Look in Spam/Junk and mark it “Not spam”. Check the “Send notifications to” address for typos.
It worked before and suddenly stopped
Changing your Google password revokes all app passwords. Create a new one and paste it in.
