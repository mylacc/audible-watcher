🎧 Address not recognised

Audible Watcher doesn't know the address {{ name }}, so it refused this page. This protects it from websites that try to reach it through your browser.

Is {{ name }} your own server's name? Then allow it by adding it to the AW_ALLOWED_HOSTS setting and restarting Audible Watcher. If you already allow other names, separate them with commas.

Docker Compose

In docker-compose.yml, under environment:, then run docker compose up -d:

      - AW_ALLOWED_HOSTS={{ name }}

docker run

Add -e AW_ALLOWED_HOSTS={{ name }} and recreate the container. More in “Opening it from other devices”.

Or skip all this and open the app by its IP address instead (for example http://192.168.1.20:5055): IP addresses always work.
